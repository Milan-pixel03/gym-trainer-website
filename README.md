# Apex Forge Premium Gym Trainer Website

A modern premium gym trainer landing website built with React, Next.js, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Notes

- The implementation uses the requested palette only: `#0B0B0B`, `#111111`, `#171717`, `#FFFFFF`, `#A1A1AA`, and `#FF2D2D`.
- The page includes animated sections, counters, transformation sliders, pricing cards, a smart workout generator, fitness calculators, meal plan cards, a gallery, and booking/contact sections.
- This Codex environment had Node.js available but no npm/pnpm/yarn executable on PATH, so dependency installation and a local Next build could not be completed here.
